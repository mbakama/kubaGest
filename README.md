# KubaGest

Gestion commerciale pour boutiques, alimentations et pharmacies.

- `backend/` : API commune NestJS `/api/v1`, PostgreSQL et TypeORM.
- `frontend/` : application Angular, destinée au conteneur Electron.
- `mobile/` : application **Flutter**, technologie retenue le 24 octobre 2026.
- `docs/database/` : proposition de schéma PostgreSQL et diagramme des relations.

Les deux clients partagent les données et les règles du backend. Le MVP reste connecté.

Consulter le [cahier des charges](KubaGest_Cahier_des_charges_V3.md), le [schéma proposé](docs/database/SCHEMA.md) et le [guide mobile](mobile/README.md).
